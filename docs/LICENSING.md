Aggiornato: 2026-09-20.

## Codice ForeverITA

Il codice originale di ForeverITA è distribuito con licenza **MIT**.

Vedi il file `LICENSE` nella radice del repository.

La licenza MIT permette uso, modifica e redistribuzione del codice, purché siano mantenuti l'avviso di copyright e la licenza.

## Traduzioni e dati

ForeverITA contiene o potrà contenere:

- traduzioni originali create per il progetto;
- identificatori tecnici come Quest ID;
- metadati e hash;
- termini, nomi e riferimenti appartenenti all'universo di World of Warcraft;
- testi derivati dal contenuto mostrato dal client quando necessari allo sviluppo e alla verifica.

La licenza MIT non deve essere interpretata come una concessione di diritti su marchi, personaggi, nomi, testi o altri materiali di proprietà di Blizzard Entertainment o dei rispettivi titolari.

Per le parti originali create dai contributori di ForeverITA, la licenza MIT si applica nella misura in cui tali contributori possiedono i relativi diritti.

## Materiale di terze parti

Il fatto che un repository esterno sia pubblico non significa che il suo codice o i suoi dati possano essere copiati.

Prima di riutilizzare materiale esterno bisogna verificare separatamente:

1. licenza del codice;
2. provenienza dei dati;
3. eventuali diritti sul contenuto di gioco;
4. compatibilità con le regole tecniche di ForeverITA.

Le decisioni correnti sui repository studiati sono in `THIRD_PARTY.md`.

## Regola pratica

ForeverITA preferisce:

- codice originale;
- traduzioni originali;
- terminologia ufficiale verificabile;
- dati raccolti tramite le normali API addon;
- fonti esterne usate soltanto quando licenza e provenienza sono sufficientemente chiare.

In caso di dubbio, il materiale non viene importato automaticamente.
